# FORM — acceptance-criteria

FORM is a local-first AI Product Builder that converts vague ideas into product definition, MVP scope, PRD, flow, UI direction, technical plan, iteration instructions, and Codex-ready Build Pack Markdown.

## Decisions
- Desktop-first editorial productivity workspace.
- Local Template Mode is the default; OpenAI-compatible API is optional.
- IndexedDB persistence with JSON backup/restore.
- Build Pack is the primary deliverable.
